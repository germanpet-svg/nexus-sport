Instalación

  1. Descarga GymManager.exe desde la sección Releases.
  2. Ejecútalo: se abrirá en tu navegador y creará la base de datos local.
  3. Inicia sesión con el usuario inicial y cambia la contraseña de inmediato.

Preguntas frecuentes

¿Qué es Nexus Sport?

Es un software de gestión para gimnasios que centraliza miembros, membresías, ventas, rutinas y asistencia.

¿En qué sistema funciona?

En Windows. Se ejecuta como un programa y se abre en tu navegador.

¿Necesito internet?

Los datos se guardan localmente. Algunos componentes visuales (gráficos y tablas) se cargan desde internet.

¿Maneja varias monedas?

Sí: USD, bolívares y tasas de cambio configurables.
